Register permutation visualizer

The permutation index is the destination and its value is the source: [1, 2, 0] means register 0 gets register 1, register 1 gets register 2, and register 2 gets register 0.

Register names are assigned in order: rax, rbx, rcx, rdx, rsi, rdi, then r8, r9, … Live-register input uses indices.
